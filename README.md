### 🎨 Генератор цветовых палитр
Разработал студент ЭФБО-18-24 Хачатрян Давид
Контрольная работа №5 по дисциплине «Фронтенд и бэкенд разработка»

### 📌 Функционал

Генерация случайных гармоничных палитр (3, 5 или 7 цветов)
Копирование цветов в буфер обмена (HEX / RGB) с уведомлением
Закрепление цветов при повторной генерации
Превью использования в UI (светлый / тёмный режим)
Автосохранение текущей палитры в localStorage
Генератор палитр с превью и настройками

## Продвинутый функционал
Поддержка разных типов палитр:
▪️ Аналогичная ▪️ Комплементарная ▪️ Триада ▪️ Случайная
Проверка контрастности по стандарту WCAG 2.1 (AA / AAA / Fail)
Библиотека палитр: сохранение, поиск, удаление
Экспорт в форматы:
▪️ CSS Variables ▪️ SCSS ▪️ Tailwind Config
Навигация через Vue Router
Кастомные компоненты с props и v-model


Библиотека сохранённых палитр


Экспорт палитры в CSS / SCSS / Tailwind

### 🛠️ Запуск проекта
Клонируйте репозиторий:
## git clone {ссылка на саму репозиторию}
Установите зависимости:
## npm install
Запустите проект:
## npm run dev
Приложение будет доступно по адресу: http://localhost:5173
